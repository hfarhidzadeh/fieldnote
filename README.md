# Fieldnote

Fieldnote is a lightweight prototype for predictive maintenance operations across residential properties. It brings symptom-based appliance triage, a work-order queue, and high-wear replacement parts into one place so teams can resolve common issues without waiting on a vendor.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Prototype interactions

- Search and filter the work-order queue.
- Switch between tankless water heater and dishwasher diagnostic guides.
- Create a triage item using the **New triage** form.
- View the on-site parts list and low-stock indicator.

Work orders are held in browser memory and reset when the page is reloaded. This is a front-end concept prototype, not a connected maintenance system.
